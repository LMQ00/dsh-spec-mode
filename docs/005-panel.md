# 005 界面

这份文档说明人打开「流程图」页之后看到什么、每个控件做什么。它建立在 [001 领域模型](001-domain.md) 的概念与 [002 规则与权限](002-rules.md) 的保存规则上。

## 从哪里打开

会话视图顶部的标签栏，「对话」「轨迹」之后多一页「流程图」。页面读的是**这个会话所属项目**的 `.spec/flows/`：会话 id 随每个请求发出，同一仓库的两个会话各看各的自己那份图集。

打开时先列出图集，再自动选中第一张：左栏高亮它，中间载入它，右栏载入它的简报。

## 三个问题

打开这个页面的人依次要回答：

1. 这个项目有哪些图，哪张是总览？
2. 选中的这张画的是什么，从哪一步到哪一步？
3. 它对应哪些需求，我要改哪一处？

## 布局

页面不分标签页，三块同时可见。

| 区域 | 显示什么 |
| --- | --- |
| 左栏「流程图集」 | 每张图一行：显示名、作用范围、被谁引用、它指向哪些图；读不出来的文件单独列在下面；底部「新建图」按钮 |
| 顶部工具行 | 显示名输入框、作用范围输入框、预览 / 源码切换、删除 |
| 中间 | 选中那张的渲染结果，或它的源码文本域 |
| 右栏 | 需求简报文本域，下面保存按钮与状态字 |

页面宽度不足 720px 时改成上下堆叠：图集在上、图在中、简报在下，默认打开源码视图。

打开这一页时对话输入框隐藏——改图不是一次对话轮次；切走这个标签页就恢复。

## 两种视图

中间区域同一时刻显示一种，顶部按钮在两种之间切。

| 视图 | 显示 | 数据来自 |
| --- | --- | --- |
| 渲染 | mermaid 画出的这张图 | 载入时用宿主画好的那份：模块框上已经是被引用图的标题 |
| 源码 | 文件里 ` ```mermaid ` 块的内容，原样可编辑 | 改过之后渲染的就是文本域里的字，保存写回盘上的也是它 |

宽窗口默认打开渲染，窄窗口默认打开源码；点过切换之后按点的那次来。

源码是真源：渲染是它的预览；标题、范围、简报是同一份文件里的另外三块。

## 渲染

| 项 | 行为 |
| --- | --- |
| 库 | 从 `GET /spec/flows/mermaid.js` 取，页面第一次画的时候加载一次 |
| 主题 | 跟随页面深浅色，切换时重画 |
| 重新渲染 | 源码每改 200ms 重画一次，改到一半的中间态不会被画出来 |
| 渲染失败 | 红字贴在预览下方，内容是 mermaid 抛的那句；要改的是上面那段源码 |
| 库没加载起来 | 红字提示宿主那条 `mermaid.js` 路由没通；源码仍可编辑与保存 |

## 工具条与表单

| 控件 | 作用 |
| --- | --- |
| 显示名 | 顶部输入框，改的是文件第一行 |
| 作用范围 | 顶部输入框，改的是文件第二行 |
| 预览 / 源码 | 切换中间区域；按钮上是「要去的那一边」 |
| 保存 (Ctrl/Cmd+S) | 提交 `id`、显示名、范围、源码、简报与载入时的修订号；被拒时逐条列出宿主返回的错误 |
| 删除 | 删掉这份文件；被别的图引用时显示宿主返回的拒绝原因，先确认一次 |
| 新建图 | 弹表单：编号、显示名、作用范围；新图从两个框、一条箭头的流程图开始 |
| 状态字 | `未保存` / `已保存`；保存中按钮文字是「保存中…」 |
| 重新载入 | 保存冲突时出现，取回盘上那一版 |
| 提醒 | 保存成功但图集还有警告时，原样显示宿主返回的那几条 |

## 设计原则

1. **页面不判断图合不合格。** 校验与它返回的错误都在宿主，页面原样显示；判两次就会出现两套规则。
2. **真源是文件里的 mermaid 文本。** 预览是它的渲染，改文字就是改图；位置由 mermaid 排版，页面不存坐标。
3. **一次只显示一张图。** 左栏是索引，中间是那张图，右栏是这张图的需求；找另一张图是点左栏。
4. **保存是显式动作。** 没有自动保存，也没有合并；冲突时先看盘上是什么再决定。
5. **窄窗口改形状，不改内容。** 720px 以下换堆叠布局，控件换行，字段一个不少。
6. **模块框的字来自子图。** 页面上改不了模块框的文字，改的是那张子图的显示名。
